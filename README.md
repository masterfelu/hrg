# hrg

Scripts to perform fits for QCD freezeout parameters.

## Directory structure

- `src/` - C++ source files
- `include/` - C++ headers
- `data/` - input data files used by the fitting routines
- `plots/` - generated plots written by the code
- `docs/` - documentation and auxiliary files
  - `docs/pdfs/` - reference PDFs
  - `docs/logs/` - fit logs and debugging output
  - `docs/scripts/` - build instructions
